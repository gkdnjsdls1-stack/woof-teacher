## 실행 방법

```bash
npm install
npm run dev
```

- 터미널에 나오는 주소(기본 `http://localhost:5173`)를 브라우저에서 엽니다.
- 같은 와이파이에 있는 폰에서 열려면 터미널에 함께 표시되는 `Network:` 주소를 쓰세요.
- 빌드: `npm run build` → `npm run preview`
- 타입 검사만: `npm run typecheck`
- reducer 자가 점검: `npm test` (화면 없이 하루 1회 제한·코인·날짜·아픔 규칙을 확인합니다)

> Node.js 18 이상이 필요합니다.

## 개발용 날짜 강제 변경

```
http://localhost:5173/?debugDate=2026-10-21
```

- **개발 모드(`npm run dev`)에서만** 동작합니다. `npm run build` 결과물에서는 완전히 무시됩니다.
- 날짜를 하루 넘기면 새 하루 리셋, 여러 날 넘기면 호감도 하락(−2/일, 최저 20)과 반김 연출을 확인할 수 있습니다.
- 과거 날짜를 넣으면 새 하루로 인정되지 않습니다(의도된 동작).
- 처음부터 다시 보려면 브라우저 콘솔에서 `localStorage.removeItem('dogapp:save:v1')` 후 새로고침하세요.

## 1단계에서 구현한 하루 흐름

1. 밥 주기 🍖 (+5) → 물 주기 💧 (+3) → 옷 입히기 👕 (+3)
2. 씻기기 🛁 (거품 문지르기 → 헹구기 → 수건, +5)
3. 재우기 🌙 (불 끄기 → 쿨쿨, +2)
4. 내일 예고 카드 → "내일 또 만나요 🌙" (종료 버튼 없음)

- 체크판 8칸 중 **출근·수업·산책**은 자물쇠로 보여줍니다(2~3단계에서 열림).
- 같은 날 다시 열면 자는 강아지 화면만 보이고 모든 메뉴가 잠깁니다.
