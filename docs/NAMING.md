# 앱 이름

## ✅ 확정 (2026-10-20)

| 쓰이는 곳 | 값 |
|---|---|
| 아이가 보는 제목 (한글) | **월월 선생님** |
| 폴더·패키지·주소 (영어) | **woof-teacher** |

아래는 정할 때 검토한 후보와 기준입니다. 나중에 바꾸고 싶을 때 참고용으로 남겨 둡니다.

## 결정 기준
- 홈 화면 아이콘 아래에 들어가니 **5~6글자 이내**
- 초2가 바로 읽을 수 있는 쉬운 낱말
- 강아지 이름은 아이가 첫 실행 때 직접 짓기 때문에 **제목에 특정 강아지 이름을 넣지 않는다**
- 앱 안에서 강아지가 내는 소리는 "월월"이므로 제목도 그 말맛에 맞추면 좋다

## 한글 후보

| 이름 | 글자 수 | 느낌 |
|---|---|---|
| **월월 선생님** ← 추천 | 5 | 이 앱만의 설정(1학년 담임 + 강아지 두 마리)이 제목에 바로 담긴다. 앱 안의 "월월"과 말투가 맞는다 |

| 빵빵 월월 | 4 | 빨간 오픈카 + 강아지. 재미있지만 무슨 앱인지 덜 보인다 |
| 우리 강아지 학교 | 8 | 안전한 선택이지만 평범하다 |

## 영어 표기

영어 이름은 **아이가 보는 화면 제목이 아니라** `package.json` 이름, 폴더명, 배포 주소(URL), PWA `short_name` 에 쓰입니다.
참고: 한국어 "월월"은 영어로 **"Woof woof"** (옛스럽게는 "Bow-wow"). 영어 버전을 만든다면 강아지 대사는 `Woof!`, 자는 소리는 `Zzz…`.

### "월월 선생님"을 옮기면

| 영어 | 주소용 | 비고 |
|---|---|---|
| **Woof Teacher** | `woof-teacher` | 한글과 1:1. 짧다. 다만 영어로는 "강아지인 선생님"처럼 읽힐 수 있다 |
| Woof Woof Teacher | `woof-woof-teacher` | 가장 충실한 직역. 길다 |
| Teacher Woof | `teacher-woof` | 선생님 이름이 "Woof"인 느낌 |
| **Teacher's Pets** | `teachers-pets` | 영어 관용구 "teacher's pet(선생님이 아끼는 아이)"의 말장난. 이 앱은 선생님이 실제로 강아지(pet) 두 마리를 학교에 데려가므로 뜻이 두 겹으로 맞는다. **영어권에서 가장 자연스럽게 읽힌다** |
| My Woof Class | `my-woof-class` | "내 월월 반". 선생님이 주인공이라는 게 드러난다 |
| Woof Homeroom | `woof-homeroom` | 담임(homeroom teacher) 설정을 살린 표현 |

정리: 한글 제목과 똑같이 가려면 **`Woof Teacher`**, 영어 자체로 매끄러운 건 **`Teacher's Pets`**.
