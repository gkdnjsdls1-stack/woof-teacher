## 2단계 — 출근 & 수업 (2026-10-21 추가, 브라우저에서 확인함)

SPEC 12번 2단계 **완료 기준**: 요일마다 다른 게임이 나오고, 하루 코인이 30을 넘지 않습니다.

| 항목 | 상태 | 근거 |
|---|---|---|
| 요일마다 다른 게임이 나오는가 | ✅ | 월 숫자 세기 / 화 한글 낱말 / 수 짝 맞추기 / 목 덧셈·뺄셈 / 금 시계 보기 / 토·일 소풍 — 5종 모두 화면으로 확인 |
| 하루 코인이 30을 넘지 않는가 | ✅ | 평일 10×3=30, 주말 소풍 15. 문제를 다 풀어도 그 이상 오르지 않음 |
| 같은 문제를 다시 맞히면 코인이 또 오르는가 | ✅ | 오르지 않음. `solved[i]` 가 true면 `SOLVE_QUESTION` 이 즉시 반환 — [gameReducer.ts](../src/state/gameReducer.ts) |
| 수업 도중 새로고침하면 어떻게 되는가 | ✅ | 이미 맞힌 문제는 건너뛰고 다음 문제부터. 코인도 그대로(중복 지급 없음) |
| 오답이 벌칙이 되지 않는가 | ✅ | "다시 해볼까? 🐾" 안내 후 재시도. 잃는 것 없음 |
| 목줄·입마개를 둘 다 채워야 출발하는가 | ✅ | 네 개를 다 채우기 전에는 버튼이 "🔒 아직 준비 중" |
| 드래그가 안 되는 아이도 할 수 있는가 | ✅ | 끌어다 놓기 + **탭만 해도** 아직 안 한 강아지에게 채워짐 |
| 집에 오면 입마개가 벗겨지는가 | ✅ | 착용 상태는 출근 화면 안에서만 유지(저장하지 않음) |
| 오픈카를 눌러도 보상이 없는가 | ✅ | "빵빵! 📢" 소리와 말풍선만 |
| 주말에 수업 대신 소풍이 나오는가 | ✅ | 홈 버튼도 "🧺 소풍 가기"로 바뀜 |
| 주말 소풍 코인을 두 번 받을 수 있는가 | ✅ | 소풍은 `solved[0]` 한 칸만 씁니다 |
| 하루 순서가 이어지는가 | ✅ | 밥 → 물 → 옷 → 출근 → 수업 → 씻기 → 재우기 (끝까지 한 바퀴 확인) |
