# SPEC 13번 테스트 체크리스트 — 현황

기준 시점: **2026-10-20** / 1단계 MVP 작성 완료, **실행·타입 검사 미수행**

- 🟡 **코드 보장** = 그렇게 되도록 짰고 사람 눈으로 확인했지만, 실제로 돌려보지는 못함
- ⬜ **미확인** = 실행해 봐야 알 수 있음
- ➖ **해당 없음** = 그 기능이 아직 없음 (나중 단계)

| 항목 | 상태 | 근거 / 할 일 |
|---|---|---|
| 하루 전체 플레이가 15분 이내인가 (실측) | ⬜ | 1단계만이면 3~5분 예상. 2~3단계가 붙은 뒤 다시 실측 |
| 같은 행동을 반복해도 호감도·코인이 더 오르지 않는가 | 🟡 | 보상이 `REWARD` 액션 한 곳만 통과하고 `today.done[action]`이 true면 즉시 반환 — [gameReducer.ts](../src/state/gameReducer.ts) |
| 하루를 끝낸 뒤 할 수 있는 보상 행동이 하나도 없는가 | 🟡 | `canDo()`가 `done.sleep`이면 모든 행동에 false. 밤 화면에는 쓰다듬기(보상 0)만 — [selectors.ts](../src/state/selectors.ts) |
| 며칠 안 열어도 호감도가 20 밑으로 안 내려가는가 | 🟡 | 빈 날 하루당 −2, 바닥 20. 이미 20 이하면 그대로 둠 — `decayHearts()` |
| 기기 날짜를 과거로 돌려도 새 하루가 생기지 않는가 | 🟡 | `today.date`·`lastPlayedDate` 두 값과 모두 비교해 이전이면 무시 — `dayCheck()` |
| 자정을 넘기며 켜둔 상태에서 복귀하면 새 하루로 바뀌는가 | 🟡 | `visibilitychange` + `focus` + 30초 간격 확인 — [GameContext.tsx](../src/state/GameContext.tsx) |
| 병원 화면에 무서운 표현이 없는가 | ➖ | 병원은 4단계. 주사·피·수술 표현 금지 규칙을 [CLAUDE.md](../CLAUDE.md)에 적어둠 |
| 강아지가 "월월" 계열 말만 하는가 | 🟡 | 대사는 `constants.ts`의 `BARKS` 한 곳에만 있음: 월월 / 월! / 끼잉 / 음냐…월 / 쿨쿨 + 이모지 |
| 세로 360px 폰에서 버튼이 모두 잘 눌리는가 | ⬜ | CSS에 버튼 최소 56px, 본문 18px, 360px 이하 보정을 넣었으나 실기기 미확인 |
| 한글 이름 입력이 폰 키보드에서 정상 동작하는가 | ⬜ | controlled input, `maxLength=6`, `enterKeyHint="done"`, 공백만 입력 차단. 실기기 IME 미확인 |
| 개발용 날짜 강제 변경이 개발 모드에서만 동작하는가 | 🟡 | `import.meta.env.DEV` 가드 + 날짜 형식·실존 검증. **`npm run build` 결과물에서 무시되는지 직접 확인 필요** |
